# Bellabeat-case-study
## Project Overview
This case study explores smart device usage data in order to identify user activity and sleep behavior patterns.
The analysis was completed as part of the Google Data Analytics Certificate and focuses on how data can support business decisions and user engagement strategies.
## Tools Used
- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Charts
## Analysis Process
- Cleaned and organized the dataset
- Analyzed daily activity and sleep data
- Explored user behavior patterns
- Created visualizations to support the findings
## Key Findings
- Higher levels were associated with significantly more daily steps
- Weekly activity patterns appeared relatively stable overall
- Most individual users showed low to moderate consistency in daily habits
- Average sleep duration was around 7 hours per night
- Overall weekly trends appeared stable, but individual user behavior varied significantly
## Business Recommendations
- Encourage habit-building through personalized reminders
- Segment users based on activity consistency
- Improve engagement strategies using behavioral patterns
